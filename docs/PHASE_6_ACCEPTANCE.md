# Phase 6 — Provenance Acceptance

The blueprint defines Provenance as a distinct phase and requires important
information to carry:
Source, Author, Date, Location, Evidence, Confidence, Status.

The system also tracks:
- when information was obtained
- reliability/confidence
- supporting sources
- opposing sources
- stale status

This phase adds a provenance record/store/service and API to the integrated
Tinkle system. It does not silently implement the later Knowledge Immune
System; that remains a separate phase/component in the blueprint.
