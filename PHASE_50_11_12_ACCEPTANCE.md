# Tinkle — Phase 50.11–50.12 Acceptance

## 50.11 Security Red-Team
Deterministic adversarial cases cover rate limiting, oversized tool input, permission bypass, sensitive-tool gating, sandbox file escape, and secret exposure.

## 50.12 End-to-End
API/UI smoke is exercised from health/UI through project/task/memory/tool/math/integration boundaries, plus authentication failure checks.

### Limits
This is not a claim of formal security certification, kernel-level sandboxing, browser E2E, or cloud-provider penetration testing. Those require deployment-specific environments.
